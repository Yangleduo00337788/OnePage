PM 维护。目标要可验证。避免只写「做好体验」「提升质量」。

## 产品目标

| 目标 | 指标 | 期限 |
| --- | --- | --- |
| 七角色模板齐全 | 每个角色职责在 MD 中有对应页或章节 | 模版发布时 |
| 本地可写回 | 授权后保存即改磁盘文件 | 模版发布时 |
| （当前项目） |  |  |

## 用户目标

- 主用户是谁：项目成员、新成员、Agent
- 完成什么任务算成功：按角色找到并改完自己的文档，不必问人要链接

## 技术目标

- 架构 / 性能 / 可维护性：文档增量 = 加 MD；Vue 壳保持一份文档页
- 明确不追求：自建后端、服务端渲染 CMS、全浏览器 File System Access

## 交付目标

- 里程碑：见 [项目管理](/delivery/management)
- 上线形态：静态 `dist/` 或随仓库本地 `npm run dev`

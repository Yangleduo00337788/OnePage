本组记录 ONEPAGE 本机压测：压什么、用哪份脚本、跑出什么数，以及压测里发现的缺陷。功能用例仍在 [执行记录](/quality/run)；这里只收容量和并发问题。

脚本在仓库根目录 `loadtest/`，工具是 k6（本机 `D:\yangleduo\Develop\K6`，已进 PATH）。网关地址默认 `http://127.0.0.1:8080`。账号密码只从环境变量 `K6_ACCOUNT`、`K6_PASSWORD` 读，不写进文档。

## 现在测什么

先测登录后的读路径。500 并发那一轮把注册和登录放进每一轮，不测发帖、上传、开播。

| 脚本 | 做什么 | 状态 |
| --- | --- | --- |
| `loadtest/read-smoke.js` | 1 个并发、1 次迭代：登录、发现流、笔记详情、评论、作者主页 | 2026-10-30 通过，5/5 为 200。这组延迟是冷启动，不当容量结论 |
| `loadtest/read-ramp.js` | 登录一次后复用 `ONEPAGE_SESSION`。并发 20 → 50 → 100，每档先爬 30 秒再保持 3 分钟，最后 30 秒降到 0。全程约 11 分钟 | 2026-10-30 未过，见 [LT-001](/quality/loadtest/bugs/lt-001)。同日连接池后再跑仍未过，见 [LT-002](/quality/loadtest/bugs/lt-002)。本机额度改为 2000/4000 后再跑通过：HTTP 失败率 0%，约每秒 372 次请求 |
| `loadtest/auth-read-500.js` | 每一轮新邮箱注册、再登录，然后发现流、详情、评论、作者主页。并发 100 → 250 → 500，每档保持 3 分钟，全程约 11 分钟 | 2026-10-31 等待 15 秒后通过。见下文「500 并发」 |
| `loadtest/login-ramp.js` | 已有账号反复登录，不注册。并发 100 保持 3 分钟，再 200 保持 3 分钟 | 2026-10-31 通过。见 [登录报告](/quality/loadtest/reports/r-login)。QPS（吞吐量）约 124，P95 1.73 秒，失败率 0 |
| `loadtest/search-ramp.js` | 公开搜索。每一轮查笔记、用户、话题、在播。并发 100 → 250 → 500，每档保持 3 分钟，全程约 11 分钟。关键词默认「一」，可用 `K6_SEARCH_Q` 换 | 2026-11-01 通过。见 [搜索报告](/quality/loadtest/reports/r-search)。每个 Tab 约每秒 631 次，P95 222 毫秒，失败率 0 |
| `loadtest/post-ramp.js` | 登录一次。每一轮申请图片上传凭证，再发一篇纯文本、仅自己可见的笔记。不上传文件。并发 100 → 250 → 500 | 2026-11-01 通过。见 [发笔记报告](/quality/loadtest/reports/r-post)。凭证和发笔记各约每秒 373 次，发笔记 P95 701 毫秒，失败率 0 |
| `loadtest/react-ramp.js` | 登录一次。对发现流里的公开笔记点赞、收藏、评论。并发 20 再 50。偶数轮点上，奇数轮取消；评论每轮新写一条 | 2026-11-01 通过。见 [互动报告](/quality/loadtest/reports/r-react)。三个接口各约每秒 219 次，评论 P95 144 毫秒，失败率 0 |
| `loadtest/im-ramp.js` | 登录一次，并注册一个对端。每一轮建会话再发一条文本。并发 20 再 50 | 2026-11-01 通过。见 [私信报告](/quality/loadtest/reports/r-im)。建会话和发消息各约每秒 375 次，发消息 P95 89 毫秒，失败率 0 |
| `loadtest/live-ramp.js` | 登录一次。没有在播就开一场，不推流。每一轮拉在播列表、进这一场、拉聊天。并发 20 再 50 | 2026-11-01 通过。见 [直播报告](/quality/loadtest/reports/r-live)。三个接口各约每秒 692 次，列表 P95 37 毫秒，失败率 0 |
| `loadtest/mix-ramp.js` | 八成发现流加详情，登录和搜索各 5%，评论 4%、发仅自己可见的文字 3%、私信 3%。30 秒爬到 1000，保持 3 分钟 | 2026-11-03 按上线行为通过（DEC-093）。见 [混合 1000 报告](/quality/loadtest/reports/r-mix) |

阶梯脚本的通过线：HTTP 失败率 < 1%，检查通过率 > 99%。脚本里按接口拆的 60 秒耗时线只为让汇总分开，不是性能指标。

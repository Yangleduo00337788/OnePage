## 质量目标

- 发布前冒烟必须全过
- 角色写权限、目录授权、保存写回三条主路径无阻塞缺陷
- （当前项目补充）

## 测试范围

| 类型 | 覆盖什么 | 谁执行 | 何时必须过 |
| --- | --- | --- | --- |
| 冒烟 | 打开首页、勾选角色、授权目录、编辑保存、新建删除、侧栏展开收起 | QA | 每次发布 |
| 功能 | 七角色写权限边界、目录/文档区分、配置中心 | QA | 需求变更后 |
| 回归 | 主题、中英、搜索、上一篇下一篇 | QA | 发版前 |
| 探索 | 无 Markdown 经验的人能否改文档 | QA | 编辑相关改动后 |

## 环境

- 测试环境：`npm run dev` 或预览机
- 数据准备：使用本仓库 `src/content/` 模版数据
- 账号：无登录；用配置中心切换角色模拟身份
- 浏览器：Chrome / Edge（目录授权依赖 File System Access API）

## 发布门禁

- [ ] 冒烟全过，证据贴到执行证据页
- [ ] P0 缺陷为 0
- [ ] OP 确认 [运维与交付](/delivery/ops) 回滚步骤可执行
- [ ] POM 状态页健康度不是「阻塞」

## 体验原则

1. **文档优先：** 用户打开的是知识，不是编辑器。默认预览，需要时再编辑。
2. **角色清晰：** 能改和不能改一眼可辨，不把权限藏在菜单深处。
3. **目录可扫：** 文件夹和文档有不同图标，层级不超过大脑负担。
4. （当前项目补充）

## 界面约定

- 布局（产品站 PC）：190px 左栏 + 首页顶栏居中搜索条（其它页改右上搜索图标，点开再输入）+ 分类 Tab 居中 + 瀑布流笔记（卡片 280×440，封面铺满不留左右白边）。点卡片弹出帖子详情（不换路由，从该卡片放大，关闭收回并滚回该帖，开合同为 520ms）：图文左栏宽度跟图片比例走，不留左右黑边（悬停出页码、左右切图、底点）；视频帖左侧播视频（contain、自动播；悬停底栏：play/pause 无外圈、时间、分辨率、文字倍速、音量、画中画、全屏；暂停时正中放大 play；菜单可点；画中画关详情后仍播）；右栏顶头像+昵称（悬停出宽 360 作者卡，底三图固定尺寸；卡内头像/昵称/关注/粉丝/获赞和收藏/帖图进作者主页 `/u/:pageId`）+圆角 20px 红「关注」（自己的帖不出现）+关闭（悬停灰圆）；标题加粗、正文次要色，话题，时间·IP 与更多（举报），中评论，底 20px 圆角输入 + 点赞/收藏/评论/分享（每钮 48px；底栏高度固定 48px。点输入后四钮向右折叠，右侧圆角 20px 红按钮「发送」）。分享弹层「分享至」：列出会话与关注好友，点发送走 `POST /posts/{id}/share/im`；没有人时用空态，底复制链接。切换分类时 Tab 下方只出旋转圈、帖子先下移再换新。向下滚动无限加载下一批。隐藏右侧原生滚动条。右下角返回顶部 / 刷新（悬停出提示）。首页不展示右侧正在直播、热门话题、宣传图。首页/视频瀑布流接真实 Feed；点卡片拉详情与评论，赞藏评未登录先登录。评论输入 `@` 后在输入框上方列出匹配的人（已关注或昵称/一页号），点选写入；被 @ 的人在「评论和@」收到「提到了你」；点评论里的 @ 关详情进主页。视频卡封面播首帧不要空灰底；纯文字封面社区与创作者同一套：封面只放大加粗标题居中，不铺摘要。视频页同瀑布流、无分类，只展示视频帖。直播页保留分类 Tab，无房间时空态，不用假封面。详情作者卡资料走 `GET /users/{pageId}`；关注走接口；举报弹层 `POST /reports`（原因灰胶囊，选中红底白字，不要用会被全局 `button{background:none}` 吃掉的 Tailwind `bg-*`）。时间只展示接口 `publishedAt`，不编 IP 与假话题。
- 选中胶囊内「图标+两字」居中；耶耶 / 关于我们左对齐其它导航。侧栏「发布」选中灰底，右侧仍是首页，同时新开创作者中心。
- 「我的」笔记空态「去发布」同样打开创作者中心。
- 未登录时侧栏「我的」换成红胶囊「登录」，点开登录弹窗。详情里点赞/评论/关注/分享/举报同样立刻出登录弹窗（`z-[100]`），不要被详情挡住。
- 搜索页不显示「全局搜索 / 关键词」大标题。分类行 16px，选中 18px 红下划线。最右「筛选」40×20px 胶囊：默认无灰选中，悬停才出灰底并展开条件面板（不是点击）。按钮到面板有悬停热区，可直接点选项。面板 440px 右对齐，条件网格对齐，选项 14px / 36px 高 / 20px 圆角，选中红底。可重置或收起。点「问耶耶」带 `q` 进 `/yehyeh`。
- 通知页上方居中三 Tab（评论和@、点赞和收藏、新增关注），样式同首页分类；下列表示互动提醒，不是私信。接 `GET /notifications?group=comment|reaction|follow`。未登录弹登录。点关注类进主页，有笔记的打开详情。评论/回复展示正文摘要。列表加载后把本 Tab 标已读。侧栏「通知」与三个 Tab 均可出未读数。本期行内不展示笔记封面。
- 消息页无顶栏、无搜索，左右分栏铺满视口。接 `GET/POST /conversations` 与消息接口。未登录弹登录。他人主页消息钮会开或复用单聊。气泡旁出头像（对方左、自己右）。登录后 `WS /ws/im` 收新消息；断线才约 3 秒轮询。发文本走 REST；输入条左侧图片钮走 `im_image` 预签名直传，气泡出图，点开全屏看。
- 他人主页 `/u/:pageId`：资料接真实接口；笔记 Tab 接 `GET /users/{pageId}/posts`（只出公开）；关注/取关走接口；点关注/粉丝数字出列表弹层；举报弹层 `POST /reports`；消息圆钮 `POST /conversations` 后进 `/messages?c=`。
- 关于我们：三张装饰卡可拖；协议 / 隐私 / 帮助点开弹窗不离开本页。创作者弹窗点打开则跳到创作者站点。直达 `/privacy` 等路由仍可用。
- 运营后台：内部站 :5176。未登录先看独立登录（无注册、无去社区开户）。登录后左栏工作台（数字 + ECharts）；「治理」「内容」点开才出二级（与创作者「数据报表」同一套左对齐折叠）。治理含工单、用户、私信。私信列表双方+最近预览；点查看弹层看消息，可隐藏/恢复（对用户不可见）或冻结发送人。搜用户 ID 或会话 ID。用户点「筛选」会按一页号/昵称重拉列表。表格底部分页靠右。分类/活动/话题点新增或编辑出弹窗。活动封面点选上传并裁剪，裁完立刻在格子里出图，不要等公网地址。滚动条全部隐藏，滚轮仍可滚动。点笔记或工单对象在本站弹层预览，不跳社区。直播/搜索/AI 不进菜单。不要从社区侧栏入口进来。
- 创作者中心：用户后台。主区不显示「一页 · 创作者中心」标题，只留右上角头像菜单。左栏、顶栏、上传区、说明输入底 `rgb(248, 248, 248)`。首页与发布页都是 20px 白卡片、右边和下边留页边。首页左资料、新创作入口、数据总览、话题；右侧空位放待处理、最近笔记、公告、活动。草稿进发布页，审核中/最近笔记进笔记管理，活动进活动中心。图文/视频进发布；开播去社区直播页。笔记管理顶栏切全部/已发布/审核中/未通过，右切卡片/列表并搜标题；列表接本人已发布笔记（含仅自己），卡片只展示分类和仅自己可见，不展示原创/类型/活动；视频封面用文件首帧，不要用 img 去加载 mp4。悬停封面出预览（眼）和编辑（笔）两个白圆钮；预览在创作者中心弹层看正文和媒体，不跳社区。编辑进入发布编辑页，保存走 `PATCH /posts/{id}`。可批量设私密/删除。审核中/未通过尚未接入，切过去说明「审核尚未接入」。无匹配显示「没有找到相关笔记」。首页「最近笔记」同一接口，待处理草稿/审核数量暂为 0。数据报表标题与周期同一行横排，说明文字不要竖排。账号概览看整体热度；内容分析按篇；粉丝数据看涨粉取关。左栏顶放与社区同一套设计稿锁套，收起为透明底红书 favicon。发布是收进栏内的红胶囊（图标、文字、箭头一组），导航图标一列左对齐、灰色字；首页与其他项同一条线。点击发布进发布页，悬停弹出体裁。发布落地页只有上传提示，不出现标题正文。点上传后图片先裁 3:4（视频不裁）再进编辑页（图片条 + 文案卡 + 笔记分类 + 内容设置 + 关联活动 + 更多设置 + 底栏暂存/发布）。缩略图可再裁。分类必选，写入 `post.category`，首页 Tab 按它筛。发出写入原创、内容类型、活动（服务端目录快照标题）、可见范围（公开进发现流，仅自己不对别人展示）。好友可见与定时发布尚未接入，打开后不能发出。原创、内容类型、关联活动只在帖子详情（含创作者预览弹层）展示，瀑布流和笔记管理列表不展示。发布体裁只保留视频 / 图文 / 长文。活动中心按进行中/预告筛选，封面是左侧小图（真实照片，不是色块）；创作字典按分类切、可搜问答。发布页三个体裁 Tab 选中灰底 20px 圆角。未登录先看独立登录页：不拆左右栏。整页一张自绘背景（米色纸 + 中部生活拼贴），Logo 叠左上，登录卡绝对定位在右侧，圆角 20px、**纯白**底。只登录不注册。退出回到登录页。
- 耶耶页不显示顶搜。默认收起历史栏，展开/新建为圆形灰选中钮。点开后 249px 栏贴在导航右侧。问候与输入卡主区居中；白底输入卡圆角 20px、描边略深；未改字点「问耶耶」走预设；点输入框时卡片顶部不动、向下延伸（约 280ms）露出三条快捷问题（默认无灰底，悬停才 20px 圆角选中；手改文字后收起并点亮发送）。无首页能力卡、无对话底栏芯片。加号菜单三项悬停 20px 圆角、图标 20px。对话顶栏标题、用户灰气泡、AI 无气泡、底栏免责声明。模型未接入时回复明确「暂时不能回答」，不编造内容。
- 点侧栏「更多」出 180px 弹窗（左对齐选中胶囊，无右侧遮罩）。点菜单项在弹窗内进三级页，返回键回到上一级，不换独立页面。主题模式一行、图标滑块切换（系统/浅色/深色）。
- 登录弹窗 800×480，左右各半：左为英文 Logo、装饰，扫码区标明即将接入（不画假码）；右为表单。勾选框与协议文案水平对齐。登录、注册默认不勾选协议，未勾选提交提示「请先阅读并同意用户协议和隐私协议」。注册：昵称可选；手机号、邮箱至少填一项（框上不标「可选」）。密码 Tab 有「忘记密码」（手机验证码 + 新密码，重置并登录）。设密/改密在侧栏「更多」里（退出登录上方；未登录不显示）。点「获取验证码」须有发送中 / 倒计时 / 成功或失败文案，不能无反馈。登录后若 Session 没种上，弹窗留着并提示，不要闪一下关掉。
- 「我的」按整页铺，无顶栏白条。封面通栏铺到 Tab 上方分割线；头像、昵称、一页号、签名、关注/粉丝/获赞与收藏叠在封面上。点关注/粉丝数字出列表弹层。点获赞与收藏出获赞/被收藏弹层。展示 `一页号：`、`签名：`（空为暂无）。搜索、编辑、退出登录在封面右上同一组白字胶囊。昵称旁用男女图标，未设置不显示。点封面/头像先裁剪再直传。点编辑弹窗改昵称/签名/性别。点一页号复制。资料下分割线，四个 Tab：笔记 / 收藏 / 点赞 / 历史。笔记 Tab 接 `GET /users/{pageId}/posts`（作者含仅自己可见）；收藏/点赞/历史接 `GET /users/me/favorites` `/likes` `/history`。卡片同首页，点开详情。切 Tab 按左右方向横滑切换。无内容时空态：上方共用插画 `empty-me.png`；笔记去创作者中心发布（红胶囊），其余去首页（灰胶囊）。未登录进 `/me` 打开登录弹窗并回到首页。
- 布局（文档壳）：顶栏 + 左侧导航 + 正文 + 本页目录。
- 圆角、间距、字号与现有 UI 保持一致，不另起一套视觉语言
- 深浅色都要可阅读，不要用纯装饰色当正文色

## 无障碍与反馈

- 关键操作有按钮文案 / `aria-label`
- 加载、空态、失败各写一句用户能看懂的说明。空态上方用粘土插画（见视觉规范「空态插画」），不要再用灰圆图标。
- 保存成功、无权限、未授权目录三种反馈文案固定，不写技术堆栈

## 颜色与字体

产品站 PC（ONEPAGE shell，实现以本表为准；静态原型图仅作构图参考）：

| 用途 | 值 |
| --- | --- |
| 左栏底 | `#fafafa` |
| 主区 / 顶栏底 | `#ffffff` |
| 正文 | `#1f1f1f` |
| 次要文字 | `#8a8a8a` |
| 导航选中 / 悬停胶囊 | `#f2f2f2` |
| 强调红（耶耶 AI 标） | `#ff2442` |
| LIVE | `#ff4d4f` |
| 封面占位 | `#ececec` |
| 笔记封面悬停 | 封面叠 `black/25`，无缩放、无位移 |

文档壳颜色 / 字体：沿用工作空间 token（`src/styles/globals.css`），不另起一套。正文、次要文字、边框、强调色都要在浅色 / 深色下可分辨。地址栏图标与社区 / 创作者相同：`favicon-32.png`、`favicon.png`、`apple-touch-icon.png`（不要再用带字母 A 的 SVG）。顶栏 Logo 右侧固定文案 **Workspace**（13px、次要色），标明这是文档工作空间而不是产品站。顶栏左侧内边距 **24px**（`pl-6`），与侧栏 `px-6` 对齐，文字不要贴窗口边。侧栏「文档目录」行右侧：显示 **N 篇**（11px 次要色，悬停说明不含空间配置）+ 7×7 加号钮；点开菜单「新建文档 / 新建子目录」。

## 左栏信息架构

上：首页、耶耶（旁红底 AI）、视频、直播、发布、通知、消息；已登录为「我的」，未登录改为 130px 红底白字「登录」按钮。侧栏「发布」进 `/create`：灰底选中，右侧仍是首页瀑布流，同时新标签打开创作者中心。不要空白页。  
下：更多（点击弹窗，不进独立页）、关于我们。不要黑底「发布」主按钮。

「更多」弹窗：菜单宽 **180px**，左边缘与「更多」选中胶囊对齐，浮在按钮上方，**无右侧遮罩**。点进项后在同一弹窗出三级页（宽 320px，左上返回），不跳独立路由；**创作者中心除外**：右侧 `arrow-up-right` 14px `#bbb`，直接新开标签进独立站，当前社区页不动。创作者站点、文档工作空间（:5173）地址栏用与社区相同的 Logo favicon。主题模式同一行：右侧 28px 高滑块，显示器 / 太阳 / 月亮图标，滑块跟手。顺序：隐私、协议、帮助与客服；分割线；创作者中心、业务合作（三级：主播入驻 / 大 V 认证）；分割线；键盘快捷键、添加 ONEPAGE 到桌面；分割线；主题滑块；已登录为设置/修改密码；退出登录。

选中胶囊内以「图标 + 两个字」为居中基准。耶耶的 AI、关于我们多出的两字不参与居中，图标和文字起点与其它项左对齐，多出部分向右排。

## 组件状态

| 组件 | 默认 | 悬停 | 选中 / 展开 | 禁用 |
| --- | --- | --- | --- | --- |
| 产品左栏导航 | 透明底 | `#f2f2f2` 胶囊 | 同悬停 | — |
| 笔记封面 | 原图 | 封面加深（`black/25`） | 同悬停 | — |
| 分类 Tab | `#8a8a8a` 17px | `#555` | 20px semibold `#ff2442` + scale | — |
| 文档壳导航项 | 次要文字 | 浅底 | 强调底 + 中黑字 | 无权限时降低透明度 |

## 图标（文档壳）

- 目录：文件夹
- 文档：文件
- 空间配置：宫格图标
- 不要用颜色作为唯一含义（同时用图标 + 文字）
